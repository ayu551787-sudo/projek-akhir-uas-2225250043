Jelajah SPLDV

Aplikasi Web Pembelajaran Sistem Persamaan Linear Dua Variabel

Tentang Aplikasi

Aplikasi web pembelajaran Sistem Persamaan Linear Dua Variabel (SPLDV) untuk siswa SMP (kelas VIII–IX). Aplikasi ini dirancang untuk mengurangi beban kognitif (cognitive load) siswa sehingga kemampuan literasi matematika mereka berkembang.

Aplikasi dapat dibuka dari browser smartphone maupun laptop/PC.

Latar Belakang Perancangan

Perancangan aplikasi ini didasarkan pada wawancara analisis kebutuhan dengan siswa kelas IX. Kesimpulan utamanya:

Temuan Wawancara Jenis Beban Jawaban Aplikasi
Kesulitan memahami soal cerita yang panjang dan memodelkannya. Beban Asing (Extraneous) Pemecahan informasi soal cerita menjadi poin-poin terstruktur dan panduan bertahap.
Kebingungan dalam menentukan langkah eliminasi maupun substitusi. Beban Kognitif (Intrinsic & Germane) Simulasi langkah penyelesaian otomatis yang transparan dan mudah diikuti.
