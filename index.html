Jelajah SPLDV

Aplikasi web pembelajaran Sistem Persamaan Linear Dua Variabel

Tentang Aplikasi

Aplikasi web pembelajaran Sistem Persamaan Linear Dua Variabel (SPLDV) untuk siswa SMP (kelas VIII–IX). Aplikasi ini dirancang untuk mengurangi beban kognitif (cognitive load) siswa sehingga kemampuan literasi matematika (matematika literasi) mereka berkembang.

Aplikasi dapat dibuka dari browser smartphone maupun laptop/PC.

* Nama "Jelajah SPLDV" masih nama kerja dan dapat diganti.
